# Capturas del sistema

Cada archivo es una pantalla del sistema andando, con datos de prueba.
Se sacan solas con el script que maneja un navegador Chromium por su
protocolo de depuracion, asi que se pueden volver a generar cuando el
front cambie.

| Archivo | Que muestra |
|---|---|
| 01-login | La pantalla de ingreso |
| 02-tablero | El taller en columnas por estado, con las tarjetas que se arrastran |
| 03-ordenes | Las ordenes que estan adentro del taller |
| 04-ordenes-entregadas | El archivo: las entregadas por rango de fechas |
| 05-presupuestos | Presupuestos con sus opciones y vencimiento |
| 06-clientes | Clientes |
| 07-vehiculos | Vehiculos y su cliente |
| 08-deposito | Stock de repuestos, con el lector de codigo de barras |
| 09-venta-mostrador | Venta de repuestos sueltos |
| 10-caja | El arqueo del dia: ordenes y mostrador juntos |
| 11-empleados | Alta de usuarios, roles y bloqueo de acceso |
| 12-sucursales | Sucursales |
| 13-datos-del-taller | Datos fiscales y adonde paga el cliente |
| 14-cobro-y-recibo | El cobro de una orden con su recibo impreso |
| 15-acciones-de-la-fila | El menu de acciones de una orden |
| 16-buscador-click-derecho | El buscador que sale con el click derecho sobre una tabla |
| 17-confirmacion | Un cartel de confirmacion antes de borrar |
| 18-vista-de-un-mecanico | El mismo sistema visto por alguien que no es administrador |
